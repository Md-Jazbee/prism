# Security Policy

Report suspected vulnerabilities privately to the maintainers (open a private advisory on GitHub when available, or contact the repo owner).

## Scope

- Local-first indexing and MCP tools
- Plugin extractors (must remain pure transforms)
- Evidence Packs that may be sent to LLMs

See [docs/security/RELEASE-CHECKLIST.md](docs/security/RELEASE-CHECKLIST.md) and [docs/security/AUDIT-AND-REDACTION.md](docs/security/AUDIT-AND-REDACTION.md).
